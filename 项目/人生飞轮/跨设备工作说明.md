# 跨设备工作说明

## 初次使用

私有仓库：https://github.com/fangjiaqi2023-jpg/life-flywheel

克隆命令：`git clone https://github.com/fangjiaqi2023-jpg/life-flywheel.git`

当前设备工作目录：`E:\飞轮系统`，默认分支为`main`。

2026-10-24同步状态：私有仓库已建立，首批文件通过已授权GitHub连接器上传。本机命令行Git认证尚未完成，本地与远程初始提交历史不同，暂不能直接pull/push；后续衔接应保留双方历史，不强制覆盖。其他设备从远程clone不受此问题影响。

在另一台设备安装Git，登录自己的GitHub账号，克隆本项目私有仓库，再用编辑器或Codex打开克隆目录。具体克隆地址见GitHub仓库的Code按钮；不要把账号凭据放进仓库或聊天。

## 每次工作

1. 开始前检查 `git status`；工作区干净时运行 `git pull --ff-only`。
2. 请助手先读根目录AGENTS.md及项目推进图，按最新接续位置继续。
3. 结束前更新文档和下一步，检查 `git diff` 与待提交文件，提交后 `git push`。
4. 确认推送成功后再切换设备，避免两台设备同时改同一文件。

有本地改动或分叉时先保留并核对双方内容，不用强制覆盖。聊天历史不会随Git同步；重要结论必须保存为项目文档。

## 同步范围

同步：人生飞轮项目文档、README、AGENTS及Git配置说明文件。

不同步：书籍全文、Obsidian本地设置、临时工具和其他项目。新设备缺少原文时，可以阅读已保存的释义和架构；需要回查原文时另行放置合法来源文件。

维护发生在用户与助手实际工作的会话中，不代表助手会在会话外持续监控或自动推送。
