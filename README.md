# 人生飞轮

人生飞轮是为我的自我实现服务的统摄性项目与基础设施。自我实现指：知道自己为什么而活，并按认可的方向生活，逐步成为自己满意的人。以自己自主认可的目标为方向，提升实现目标的能力，并持续行动、反馈和修订。各项目的具体服务关系及价值权衡方法仍在共同澄清中。

当前阶段：以智能为主要视角共同推导目标选择与实现，按小步讨论并分别记录确认范围。最新确认位置及下一项见[项目推进图](项目/人生飞轮/项目推进图.md)。尚未实践验证；方法论与架构v0.1保留为初稿。
